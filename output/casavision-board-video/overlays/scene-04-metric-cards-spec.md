# Scene 04 — Metric Card Overlays: Canva Specification

**Project:** CasaVision Executive Board Video (60s)
**Scene:** Scene 4 — Results (dark background)
**Canvas size:** 1920 × 1080 px (transparent background)
**Output format:** PNG with transparent background

---

## Overview

Four metric card overlays appear sequentially on top of Scene 4's dark background. Each card is a standalone transparent PNG containing a large metric number and a label stacked vertically, centered in the frame. Because these overlays sit on a dark video background, pure white text with no drop shadow is used — the dark background provides sufficient contrast.

---

## Shared Style Reference

| Property | Value |
|---|---|
| Canvas size | 1920 × 1080 px |
| Background | Transparent |
| Number font | Montserrat ExtraBold |
| Number size | ~120 px |
| Number color | White (#FFFFFF) |
| Label font | Montserrat Regular |
| Label size | ~40 px |
| Label color | White (#FFFFFF) |
| Alignment | Center-aligned (both number and label) |
| Position | Center of frame (horizontally and vertically) |
| Drop shadow | None (dark video background provides contrast) |
| Layout | Number on top, label directly below, both stacked and centered |

## Card 1 — Results Metric

**Appears at:** 00:42
**Large number:** `52,800`
**Label:** `Suscriptores Activos`
**Export filename:** `overlays/scene-04-card-01.png`

### Step-by-Step Canva Instructions

1. **Create a new design**
   - Go to [canva.com](https://canva.com) and click **Create a design**
   - Select **Custom size**
   - Enter **Width: 1920** and **Height: 1080**, units set to **px**
   - Click **Create new design**

2. **Set the background to transparent**
   - In the design editor, click the background area
   - Delete the default white background layer, or click the background color swatch and set it to **No color / Transparent**
   - The canvas should display a checkerboard pattern indicating transparency

3. **Add the large number text element**
   - Click **Text** in the left sidebar → **Add a text box**
   - Type: `52,800`
   - Font: **Montserrat**, weight: **ExtraBold** (select from the font weight dropdown)
   - Font size: **120 px**
   - Font color: **#FFFFFF** (pure white)
   - Alignment: **Center**

4. **Add the label text element**
   - Click **Text** → **Add a text box**
   - Type: `Suscriptores Activos`
   - Font: **Montserrat**, weight: **Regular**
   - Font size: **40 px**
   - Font color: **#FFFFFF**
   - Alignment: **Center**

5. **Position and stack the two text elements**
   - Select the number text box and open the **Position** panel (top toolbar → **Position**)
   - Center horizontally: set **X** so the text box is centered at **960 px** (use Canva's center alignment button or set X manually based on text box width)
   - Position the number vertically slightly above center (Y: approximately **440 px** to allow room for the label below)
   - Select the label text box and position it directly below the number, centered at the same X axis
   - Label Y: approximately **590 px** (adjust so there is a small visual gap between the number and label)
   - Use Canva's **Align** tools to ensure both elements are horizontally centered relative to the canvas:
     - Select both elements → right-click → **Align** → **Center horizontally**

6. **No drop shadow needed**
   - Do not apply any shadow effects to these elements
   - The dark video background in Scene 4 provides sufficient contrast for pure white text

7. **Download as transparent PNG**
   - Click **File** → **Download**
   - Select **PNG** as the file type
   - Check the box for **Transparent background**
   - Click **Download**

8. **Rename the file**
   - Rename to: `scene-04-card-01.png`
   - Place in the `overlays/` folder

## Note on Scene 4 Typography Rationale

Scene 4 has a dark video background by design. Pure white text (#FFFFFF) on a dark background already achieves strong contrast (WCAG AAA equivalent). Adding a drop shadow would introduce visual noise and soften the clean, authoritative feel appropriate for board-level metric presentation. Omitting the shadow keeps the numbers crisp and legible at any screen size.
