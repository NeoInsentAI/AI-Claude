# Scene 03 — Text Overlay Cards: Canva Specification

**Project:** CasaVision Executive Board Video (60s)
**Scene:** Scene 3 — Action Vignettes
**Canvas size:** 1920 × 1080 px (transparent background)
**Output format:** PNG with transparent background

---

## Overview

Three text overlay cards appear sequentially on top of Scene 3's action vignettes. Each card is a standalone transparent PNG that sits on top of the video frame in post-production. All three cards share identical typography, positioning, and shadow styling for visual consistency.

---

## Shared Style Reference

| Property | Value |
|---|---|
| Font family | Montserrat Bold |
| Font size | ~80 px |
| Font color | White (#FFFFFF) |
| Alignment | Left-aligned |
| Position | Lower-left quadrant — ~10% from left edge, ~75% down from top |
| Drop shadow offset | X: 2px, Y: 2px |
| Drop shadow blur | 8px |
| Drop shadow opacity | 40% |
| Drop shadow color | Black (#000000) |

## Card 1 — Scene 3, Vignette A (Fiber Install)

**Appears at:** 00:22
**Text:** `18 Nuevos Barrios`
**Export filename:** `overlays/scene-03-text-01.png`

### Step-by-Step Canva Instructions

1. **Create a new design**
   - Go to [canva.com](https://canva.com) and click **Create a design**
   - Select **Custom size**
   - Enter **Width: 1920** and **Height: 1080**, units set to **px**
   - Click **Create new design**

2. **Set the background to transparent**
   - In the design editor, click the background (the white canvas area)
   - In the left panel, click **Background** (or press **B**)
   - If a default white background layer exists, select it and press **Delete**
   - Alternatively: click the background color swatch at the top toolbar and set it to **No color / Transparent**
   - The canvas should display a checkerboard pattern indicating transparency

3. **Add the text element**
   - Click **Text** in the left sidebar (or press **T**)
   - Click **Add a text box** and type: `18 Nuevos Barrios`
   - In the font selector at the top, search for and select **Montserrat**
   - Set the font weight to **Bold**
   - Set the font size to **80** (type directly in the size field)
   - Set the font color to **#FFFFFF** (pure white) using the color picker

4. **Position the text element**
   - Click the text box to select it
   - Open the **Position** panel: click **Position** in the top toolbar (or right-click → **Position**)
   - Set **X position:** approximately **192 px** (10% of 1920)
   - Set **Y position:** approximately **810 px** (75% of 1080)
   - Alternatively, drag the text element manually to the lower-left area of the canvas, roughly 10% from the left edge and 75% from the top

5. **Apply the drop shadow**
   - With the text element selected, click **Effects** in the top toolbar
   - In the Effects panel, enable **Shadow** (or **Drop Shadow**)
   - Set the following values:
     - **Direction / Offset X:** 2 px
     - **Offset Y:** 2 px
     - **Blur:** 8 px
     - **Opacity:** 40%
     - **Color:** Black (#000000)

6. **Download as transparent PNG**
   - Click **File** → **Download** (or the download icon in the top-right corner)
   - Select **PNG** as the file type
   - Check the box for **Transparent background**
   - Click **Download**

7. **Rename the file**
   - After downloading, rename the file to: `scene-03-text-01.png`
   - Place the file in the `overlays/` folder
